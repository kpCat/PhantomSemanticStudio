# Подэтап C — вручную выбранные игровые логи и русский транслит

## Context
PSS-006 has immutable SQLite corpus in `workspace/corpora`, no private TELL/FRIENDTELL rows, `ChatCorpusForm` with <=20 selected public snippets, labels `SOURCE_MATERIAL_ONLY`, preview `CorpusRecord.Preview = best-effort Scrub(Original)`. Raw public text can still contain real-person identifiers; scrub is not a privacy guarantee. `chat.zip` in `artifacts/private-input/` is **user private**, not part of task ZIP or Git.

## Required workflow
1. From Lab or existing ChatCorpusForm open corpus picker; choose corpus id and manually mark 1–20 *public* rows, select dialog action «Передать выбранное в лабораторию» with **explicit confirmation** showing full preview. Selecting is never submitting to LM. Return detached immutable references and **sanitized copied previews only** (not `CorpusRecord.Original`), source corpus/id/hash/channel/unknown timezone+language, a `SOURCE_MATERIAL_ONLY` marker. Never include speaker header, ZIP filename, raw nick or private row. Changing corpus clears selection. Do not persist raw selected text to `session.json` without further explicit editorial Save.
2. Local-only classified language labels from existing triage: CYRILLIC/MIXED/UNKNOWN/EN_OR_OTHER/LATIN_TRANSLIT_CANDIDATE; add UI manual override `RU_TRANSLIT / OTHER_LANGUAGE / UNKNOWN` for **selected excerpt only**. Avoid auto-converting all Latin to Cyrillic; `party`, `pvp`, `GG` remain game terms unless reviewed.
3. Optional Gemma operation for at most **1–3 explicitly selected excerpts per request**: `RESTORE_RU_TRANSLIT`, `TRANSLATE_TO_RUSSIAN`, `LEAVE_AS_IS/UNKNOWN` as typed output with bounded `proposedRussianText`, `languageAssessment`, `reason`, `confidence` (0..100) and source keyed ordinal IDs. Failure/uncertainty returns a recommendation, never overwrite original. This should reuse LmStudioClient loopback + strict schema/no-tools; no batch 685k processing, no automatic language detection claim.
4. Require explicit checkbox/action to allow selected sanitized snippets to be transmitted to local LM Studio, **independent of general mentor toggle**. Show exact text slated for sending; allow manual masking/edit before sending. If any excerpt still contains possible PII and user has not reviewed it, refuse send. One call max per action, no retries. Treat excerpts as untrusted user-supplied data, not instructions.
5. Result can be manually transferred to `EDITOR_NOTE` or `DRAFT` with explicit compatible existing `Topic/Act` and normal source fingerprint; nothing marked APPROVED, no XML. On target act/topic mismatch fail closed and show reason. No runtime personality/gender/mature inference. No mass native neural processing.
