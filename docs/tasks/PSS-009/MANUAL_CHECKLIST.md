# PSS-009 — ручной операторский чек-лист после Codex

Не изменять глобальный DPI без разрешения владельца. Результат отметить `PASS` только если действительно виден/воспроизведён, иначе `NOT_TESTED`.

1. При обычном текущем масштабе Windows открыть Studio стандартным `Start.cmd`. Важно: форма должна полностью помещаться на доступном экране или предоставлять достижимые scrollbars.
2. «Конструктор»: видны `Генерировать` и кнопка перехода к кандидатам, поля текста не вытесняют кнопки; вправо не уходит правый блок с настройками.
3. «Диалог и обучение»: виден ввод, ответ по паку, кнопка лаборатории, запись замечаний и работа с замечаниями; правый блок и нижние кнопки доступны.
4. «Библиотека»: видны кнопки **«Найти» и «Карта качества / ёмкость»**, полный/прокручиваемый список с колонкой «Текст» и нижняя панель деталей.
5. «Кандидаты»: кнопки save/review/approve/reject/local duplicate/Gemma полностью видны, редактор не наезжает на панель советов.
6. «Экспорт для ревью»: текст пояснений не уходит вправо; обе XML-кнопки, v3 предложение, CopyWorkspace и log доступны. На живом High Five кнопки не нажимать для установки; установка и так отсутствует.
7. «Настройки»: поля/кнопки LM/import/corpus читаемы, низ страницы и статус видны.
8. После последовательного перехода по всем вкладкам ещё раз открыть «Конструктор» и «Библиотеку»: элементы не увеличились и не переместились. Свернуть/развернуть/изменить размер окна.
9. Отдельные окна `StageSelectionForm`, `DialogueLabForm`, `ChatCorpusForm`, `PackQualityForm`, `V3ProposalForm`: проверить длинные тексты, кнопки, ScrollBars, MinimumSize, отсутствие перекрытий. Для Java/release gate использовать только вымышленные данные; реальную установку не запускать.
10. При реально доступных 100%/150% масштабах проверить читабельность кнопок, TAB и DPI. `VS 2026`: Designer open/save/reopen каждого изменённого Form, без изменений designer logic.

Если что-либо пропадает — пользовательский скриншот и имя вкладки достаточно для следующей адресной правки. Скриншоты держать локально, не добавлять в публичный Git.
