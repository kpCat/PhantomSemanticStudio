# Phantom Semantic Studio — стартовая версия 0.1

## Цель
Отдельное WinForms-приложение для контролируемого обогащения разговорного Semantic Pack High Five при помощи локальной Gemma. Пользователь работает с кандидатами и объяснениями, модель не пишет и не исполняет код.

## Неизменяемые границы
- High Five и весь L2J открываются только для чтения. Нет API публикации, кнопки установки, автоматического запуска Ant, Java, PowerShell, сервера или Git.
- Все записи выполняются только в собственном workspace в LocalAppData. Исходный каталог и workspace обязаны не пересекаться. Reparse points/symlinks в путях отклоняются.
- Экспорт — отдельный ZIP для ревью, НЕ готовый к установке релиз. Он не заменяет файлы L2J. Без серверного валидатора публикация остаётся запрещена.
- Модель получает ограниченный контекст, возвращает строгий JSON. Инструменты, команды и автоматический ремонт файлов модели не предоставляются.
- Согласование по полу и произвольные черты характера не поддерживаются действующей схемой выбора обычных реплик. Эти пожелания сохраняются как редакционные инструкции; гендерно-ограниченные кандидаты нельзя превратить в серверный XML без отдельного изменения runtime.
- Конструктор: только стандартные WinForms controls; MainForm.cs + MainForm.Designer.cs + MainForm.resx. InitializeComponent состоит из явных инициализаций/присваиваний и штатных вызовов компоновки. Constructor только InitializeComponent, I/O после Shown.

## Реализуемые потоки
Настройки → чтение исходников → библиотека/отпечаток → ограниченная генерация → автоматическая проверка → ручное редактирование и одобрение → экспорт для ревью.
Отдельная вкладка: приблизительный предпросмотр по локальному каталогу → замечание пользователя → новые кандидаты. Это не эмуляция Java-сервера и не обучение весов Gemma.

## Технологии
.NET 10, WinForms, System.Text.Json, System.Xml.Linq, HttpClient. Без сторонних NuGet-пакетов. В стартовой версии workspace хранится в атомарно заменяемых JSON-файлах, а не SQLite: меньше зависимостей для первого запуска. Замена хранилища возможна позже через WorkspaceStore.

## Проверки
C# консольный test runner без test-framework зависимостей: нормализация, дубли, строгий JSON, XML/XXE, path traversal, reparse points, журнал одобрения, source drift, экспорт, отмена и ошибочные ответы HTTP. Статическая проверка архива/Designer не заменяет компиляцию и открытие Visual Studio Designer.

## Известные пределы
Без embedding-модели смысловые дубли не доказуемы автоматически: есть точное сравнение и лексическая близость, ручное решение обязательно. Нет нового владельца отношений/памяти. Исходные v1/v2/v3/custom не переписываются. API-токен только в памяти процесса.
